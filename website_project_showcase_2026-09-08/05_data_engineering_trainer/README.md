## Interview summary

Large Data Engineering interview/practice trainer with 323 items, multi-engine SQL/pandas/PySpark comparisons, animated concepts, source previews and mastery tracking.

## Coding logic

React components separate curriculum data, editor state, source previews and visual-learning layers. Monaco handles code editing; purpose-built SVG/CSS state animations explain row/algorithm behavior; Mermaid is reserved for topology.
