# ML / Data Science Web — ML Business Atlas

**Current version/snapshot:** v6  
**Website:** https://mldatasc.netlify.app/  
**GitHub:** https://github.com/julian-passebecq/mlweb  
**Stack:** Vanilla HTML/CSS/JS · custom SVG/CSS animation · static Netlify

## Interview summary

Business-first ML and data-science explainer that lets users enter from a tool, business question or available-data lens, then learn concepts through animated visual models.

## Coding logic

The site is intentionally static: data/content models and UI state live in JavaScript, while custom HTML/SVG/CSS renders diagrams and animations. It teaches concepts without pretending to train models in-browser.
