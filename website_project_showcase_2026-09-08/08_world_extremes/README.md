## Interview summary

Interactive D3 record atlas comparing world extremes across animals, predators, aircraft, production cars, EV battery technologies and skyscrapers/towers.

## Coding logic

Plain JavaScript/D3 renders record comparisons from curated data. UI keeps record definitions visible so incomparable classes are not mixed. MediaWiki PageImages provide context thumbnails; primary/institutional sources support the values.
