# toolsdev — interview showcase handoff

This folder contains the **two active tools from the `toolsdev` project** that were developed in the current workstream:

1. **PowerToy_UI / J Utility Palette** — a lightweight standalone Windows productivity companion.
2. **VizLens Personal v1.0** — a Chrome side-panel extension for deterministic visual/article evidence recovery with optional grounded Gemini reasoning.

Each project folder contains:

- `README.md` — concise project summary, links, stack, architecture and interview talking points.
- `FEATURE_MATRIX.md` — implemented features vs. next/deferred work.
- `BACKLOG.md` — versioned next steps.
- `project.json` — machine-readable metadata for the downstream PDF/portfolio agent.
- `png/` — **5 explanatory UI scenario boards** at 1600×1000.

## Image note

The PNGs are **explanatory UI boards reconstructed from the current repository UI contracts and styles**. They are intended for interview/portfolio storytelling. They are not claimed as live runtime validation screenshots. The labels, controls, colors, workflows and product boundaries are grounded in the current repositories.
