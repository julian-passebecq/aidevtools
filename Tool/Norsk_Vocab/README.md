# Norsk Tech & Work Vocabulary

Compact Bokmål / English / French professional vocabulary atlas

- **GitHub:** https://github.com/julian-passebecq/Fluent2_J_Norsk
- **Website:** No public deployment found in current Netlify project list
- **Implementation:** React · TypeScript · Fluent UI · Datapass content/knowledge/progress · local storage

- 215 terms / 5 themes
- NB + EN + FR search
- Theme & learning-state filters
- Hide/reveal translations
- New/Learning/Review/Mastered
