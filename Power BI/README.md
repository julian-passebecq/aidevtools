## PbiBench

[PbiBench](PbiBench/) is a Windows-first C#/.NET engineering workbench concept that brings semantic-model editing, DAX workflows, automation, PBIP/Git, QA and Fabric control-plane work into one product shell.

**Runtime screenshot pending.** The current repository is a detailed implementation/handoff pack; it is not presented as a finished runtime application.
