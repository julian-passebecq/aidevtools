# MS Dev UI Showcase — GPT-5.6 Sol

Interview-oriented visual showcase pack for the active MS_Dev projects.

This folder is generated from repository evidence and public deployments. Each project gets five explanatory PNG boards plus a concise project summary, feature status and backlog. Public web apps use live deployment captures where available; local/desktop/browser-extension projects are explicitly labelled as UI reconstructions rather than literal screenshots.

Generated assets are maintained only inside this root folder so parallel AI agents can populate `aidevtools` without path collisions.
